# Summary of an SAE regression

<div class="ref-description section level2">

The global test and, per term, the directions ordered by their
bias-corrected share `q_j_cor`, with delta and its interval and the
label. The printed table leaves out alpha to give the labels room;
`summary(fit)$table` and `fit$features` hold all columns.

</div>

<div class="section level2">

## Usage

<div class="sourceCode">

``` r
# S3 method for class 'saereg'
summary(object, n = Inf, ...)
```

</div>

</div>

<div class="section level2">

## Arguments

-   object:

    An `saereg` fit.

-   n:

    Directions shown per term (all by default).

-   ...:

    Unused.

</div>
